## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or launch a quick local server using Python:

```bash
# Navigate to the project directory
cd C:\Users\Home\.gemini\antigravity\scratch\bhumika-portfolio

# Start a lightweight local server
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.

## 🌐 Deployed on GitHub Pages

This portfolio can be hosted directly on GitHub Pages:
1. In the repository settings on GitHub, navigate to **Pages**.
2. Under **Build and deployment**, select source as `Deploy from a branch`.
3. Choose branch `main` and root `/` (folder).
4. Save to get your live website URL!
